# Project-specific agent tooling

`.agents/` is the source for mcp-mixsearch-specific skills and agent definitions. Reusable planning and review skills (`impl-plan`, `design-review`, `impl-review`) and their reviewer agents come from the owner-maintained Skill Central repository and are installed per user. They are not copied or generated here and are not dependencies of CI.

| What | Canonical source | Read by Claude Code from |
| --- | --- | --- |
| Project guidance | `AGENTS.md` | `CLAUDE.md` |
| Project skills | `.agents/skills/` | `.claude/skills`, a symlink to `.agents/skills` |
| Project agents | `.agents/agents/` | `.claude/agents/`, generated by `sync_agents.py` |
| Planning and review suite, reviewer agents | Skill Central | Per-user links made by `skill-central install` |

## Skill names

Use lowercase `<domain>-<capability>` names matching the folder and the `name` frontmatter, for example `github-pr`. Never reuse a Skill Central skill's name: duplicate names make discovery ambiguous. Project skills are listed in [skills/README.md](skills/README.md); start new ones from [templates/skill/SKILL.md](templates/skill/SKILL.md).

## Agent generation

Edit only `.agents/agents/*.md` (format in [agents/README.md](agents/README.md); template in [templates/agent.md](templates/agent.md)), then run:

```bash
uv run .agents/sync_agents.py
uv run .agents/sync_agents.py --check
```

The generator writes only for the harnesses in its `ENABLED_HARNESSES` constant; see the tooling table in AGENTS.md for where each harness reads them. It prunes only files it generated. Never edit generated files.

## Session permissions

Repository settings, branch protection, secrets, force pushes, pushes to `main` and merges are prohibited for agents. `.claude/settings.json` denies those commands for Claude Code and asks before any merge. Never claim a restriction is enforced merely because a role's prose asks for it.

With no project agents yet, `sync_agents.py` only proves the generated folders are empty. Keep it: CI runs `--check`, and it is ready when the first agent arrives.
